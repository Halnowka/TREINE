# TREINE

A modern calisthenics workout tracker built with Next.js and Firebase.

## Features

- **Push/Pull Workouts**: Track your calisthenics exercises
- **Russian Fighter Program**: Follow structured progression plans
- **Progress Tracking**: Monitor your strength evolution over time
- **Rest Timer**: Built-in workout timers
- **Cloud Sync**: All data saved securely to Firebase

## Tech Stack

- Next.js 15
- React 18
- Firebase (Auth, Firestore)
- Tailwind CSS
- TypeScript

## Getting Started

1. Clone the repository
2. Copy `.env.example` to `.env.local` and fill in your Firebase credentials
3. Run `npm install`
4. Run `npm run dev`
5. Open [http://localhost:9003](http://localhost:9003)

## Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run security-check` - Check for exposed credentials
